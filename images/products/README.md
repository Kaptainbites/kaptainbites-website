# Product Image Structure

Use one folder per product slug:

- `images/products/spice-crew-cashew/`
- `images/products/mint-mond-cashew/`

Recommended image names per product:

- `primary` - default image used in cards/search/detail page
- `gallery-1`
- `gallery-2`
- `gallery-3`
- `packshot`

Examples:

- `images/products/spice-crew-cashew/primary.png`
- `images/products/spice-crew-cashew/gallery-1.jpg`
- `images/products/mint-mond-cashew/primary.jpg`

When adding a new product, create a new folder with the product slug and set the `image` path in `products-data.js`.
